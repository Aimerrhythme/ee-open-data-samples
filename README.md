# ee-open-data-samples · 电气教学数据小样

小体量的**合成数据或公开许可数据**样本 + 清洗 / 画图脚本，供课程实验、课程设计起步使用。

## ⚠️ 免责与数据来源声明
- 本仓数据**仅为合成数据**或**明确允许再分发的公开数据**（来源与许可写在每个数据集卡中）。
- **不包含任何学生个人信息（PII）**、不包含企业内部或未经授权数据。
- 合成数据仅用于教学演示，**不代表真实电网 / 电站运行情况**，不可作为工程或科研结论依据。

## 目录

```
datasets/<slug>/
  README.md          # 数据集卡（见下）
  data.csv           # 小样，建议 < 1 MB
scripts/<slug>_*.py  # 生成 / 清洗 / 画图脚本（numpy、pandas、matplotlib）
docs/dataset-convention.md
themes.md / INDEX.md
```

## 说明

- **中文为主**，必要处附英文术语。
- 本仓由定时自动化**持续追加**内容：每次从 `themes.md` 取一条 `todo` 主题 → 生成条目 → 更新 `INDEX.md` 与 `CHANGELOG.md` → 将主题标为 `done`。
- 定位为**教学材料**，**不代写**毕业设计 / 课程设计 / 论文。
- 许可：MIT（见 `LICENSE`，含教学声明）。
