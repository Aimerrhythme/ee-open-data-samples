## 1. 名称 / slug

## 2. 来源与生成方式

合成数据，不是实测。来源：本仓库脚本生成。没有真实测风塔、气象站或风电场数据。

- 生成脚本：`scripts/wind-speed_generate.py`
- 随机种子：`42`（`numpy.random.default_rng`）
- 钟面日期从 `2026-03-01` 起的六周只是标签，不含时区，不对应任何真实测风时段。
- 教学设定的测风高度是 10 m。没有地表粗糙度，也没有往轮毂高度的切变外推。

做法：

1. 生成长度 6048 的平稳标准正态 AR(1)。第 1 步直接取一个标准正态；其后

   `z_t = 0.75 · z_{t−1} + √(1 − 0.75²) · ε_t`，

   ε_t 为独立标准正态，按时间顺序消耗。潜变量的滞后 1 相关是 0.75。以 10 min 为一步，e 折时间约为 −10 / ln(0.75) ≈ 35 min。
2. 令 `u = Φ(z)`，Φ 为标准正态 CDF（`math.erf`），再把 u 裁到 `[1e-12, 1 − 1e-12]`。
3. 两参数威布尔的分位函数

   `v = 7.0 · (−ln(1 − u))^(1/2.2)`（m/s）。

   形状 k = 2.2，尺度 c = 7.0 m/s。k = 2 是瑞利分布，这里略高一点，方便练习里把 k 估出来，而不是事先当成 2。
4. 风速保留 3 位小数。

取整之前，每个时刻的边际分布都是这组 k、c 的威布尔，相邻时刻则相关。它不是独立重复抽样。两次运行脚本得到的 CSV 应逐字节相同；逐字节结果以脚本为准。

连续分布（取整前）的对照量，按 Python `math.gamma`：Γ(1 + 1/2.2) = 0.885625，所以

- 平均风速 `E[v] = c · Γ(1 + 1/k) = 6.199 m/s`
- 标准差 2.975 m/s
- `E[v³] = c³ · Γ(1 + 3/k) = 416.210`（m/s）³
- 能量模式因子 `E[v³] / (E[v])³ = 1.747`

简单的功率正比于 v³ 时，平均功率看 `E[v³]`，不是平均风速的立方。

## 5. 列说明

| 列名 | 含义 | 单位 |
|------|------|------|
| `timestamp` | 钟面时刻，ISO 8601，无时区 | — |
| `wind_speed_m_s` | 10 min 平均风速（合成）。教学用 10 m 高度，不是某一座测风塔 | m/s |

风速是按上面的威布尔边际生成的教学数值，不是某一支测风仪的记录，也不能当作轮毂高度风速。

## 6. 教学用途（练习建议）

课堂起步用，用来练习读表、画直方图和拟合分布。可自行做的练习：

1. 读入 CSV，画出风速序列（可先看前 48 h）和直方图，用极大似然或矩估计拟合 k、c，并与上表及生成参数对照。
2. 用样本均值对照 `c · Γ(1 + 1/k)`；再计算 mean(v³) / (mean v)³，看平均风速直接立方为什么对不上与 v³ 成正比的平均功率。
3. 计算滞后 1 步自相关。这些点前后相关，把 6048 当成独立样本时，不确定度会被说得偏小。

脚本只提供清洗、出图和终端里的核对数字，不代写课程作业、课程设计或论文。

## 8. 快速使用

在仓库根目录：

```bash
python scripts/wind-speed_generate.py
python scripts/wind-speed_plot.py
```

`generate` 覆盖写回 `data.csv`。`plot` 做最小清洗（解析时间、查缺失、丢掉负风速、按时间去重排序、检查 10 min 间隔），在终端打印样本矩、滞后 1 自相关和威布尔极大似然，并写出 `datasets/wind-speed/wind_speed.png`。上图是记录开头 48 h，下图是全样本直方图和拟合密度。

依赖：numpy、pandas、matplotlib。拟合在脚本内完成，不需要 scipy。

```python
import pandas as pd
df = pd.read_csv("datasets/wind-speed/data.csv", parse_dates=["timestamp"])
df.plot(x="timestamp", y="wind_speed_m_s")
```
