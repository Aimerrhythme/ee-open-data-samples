# 光伏日出力曲线（晴 / 多云 / 阴）

## 1. 名称 / slug

- 名称：光伏日出力曲线（晴 / 多云 / 阴）
- slug：`pv-daily`
- 路径：`datasets/pv-daily/data.csv`

## 2. 来源与生成方式

合成数据，不是实测。来源：本仓库脚本生成。没有真实电站、逆变器或气象站数据。

- 生成脚本：`scripts/pv-daily_generate.py`
- 随机种子：`42`（`numpy.random.default_rng`）
- 钟面日期 `2026-06-21` 只用来取夏至附近的太阳赤纬，是「一个晴空对照日」的标签，不含时区，不对应任何真实运行日。2026 年不是闰年，这一天是年内第 172 天。
- 纬度取教学用的 `30°N`，不是某座电站的站址。当地太阳时的正午固定在 `12:00`，忽略时差、时区和组件朝向。

做法：

1. 用 Cooper 近似算赤纬，再由纬度与时角得到太阳高度角。高度角 ≤ 0 的时刻晴空辐照为 0。
2. 晴空水平面总辐照用 Haurwitz（1945）钟形近似：`G_clear = 1098 · sin(α) · exp(-0.057 / sin(α))`，单位 W/m²。这是一条平滑的铃形曲线。
3. 三种天气各画一条云透射率。透射率是离散 Ornstein–Uhlenbeck 过程，随机数按晴 → 多云 → 阴的顺序消耗。相关时间以 15 min 为一步。

| 天气 | 均值 | 平稳标准差 | 相关时间 | 裁剪到 |
|------|------|------------|----------|--------|
| 晴 `sunny` | 0.96 | 0.03 | 3 步（45 min） | 0.78–1.00 |
| 多云 `cloudy` | 0.55 | 0.16 | 2.5 步（37.5 min） | 0.12–0.90 |
| 阴 `overcast` | 0.22 | 0.035 | 10 步（150 min） | 0.08–0.38 |

4. 教学额定 `P_stc = 500 kW`（GHI = 1000 W/m²、电池 25°C）。有效辐照 `G = G_clear · k`，电池温度粗算为 `T_cell = 22 + 35 · (G / 1000)`（°C）。出力

   `P = 500 · (G / 1000) · [1 − 0.004 · (T_cell − 25)]`（kW）。

5. 晴空辐照为 0 的时刻三种出力都写成 0，负值裁成 0，功率和辐照保留 3 位小数。

同一条晴空曲线配三种云，所以三列是三种天气情景，不是三座电站，也不是同一天同时测到的三条曲线。两次运行脚本得到的 CSV 应逐字节相同；逐字节结果以脚本为准。

## 4. 规模与采样间隔

- 96 行 × 5 列（约 4 KB）
- 采样间隔：15 min
- 覆盖一个典型日的钟面时刻：`2026-06-21T00:00:00` 至 `2026-06-21T23:45:00`
- 时间无时区，表示相对钟面时刻，不是带时区的绝对时间
- 本几何下白昼出力从 `05:15` 到 `18:45`（55 个点），其余 41 个时刻辐照和出力都是 0

本种子下读入后的参考量（便于核对文件，不是作业答案）。平均功率把夜间 0 算进去；容量系数 = 日平均功率 / 500 kW；日电量 = 各点功率之和 × 0.25 h。

| 列 | 最小 kW | 最大 kW | 平均 kW | 日电量 kWh | 容量系数 | 峰值时刻 |
|----|---------|---------|---------|------------|----------|----------|
| `sunny_p_kw` | 0.000 | 442.671 | 158.105 | 3794.519 | 0.316 | 12:15 |

晴空辐照 `clear_sky_ghi_w_m2`：最小 0.000 W/m²，最大 1030.008 W/m²（12:00），日辐照量 8.699 kWh/m²。

## 5. 列说明

| 列名 | 含义 | 单位 |
|------|------|------|
| `timestamp` | 典型日钟面时刻，ISO 8601，无时区 | — |
| `clear_sky_ghi_w_m2` | 晴空水平面总辐照。夜间为 0，正午附近为铃形峰值。三种天气共用这一列 | W/m² |
| `sunny_p_kw` | 晴天情景的有功出力。紧贴晴空形状，只有轻微云扰动 | kW |
| `cloudy_p_kw` | 多云情景的有功出力。云团来去，曲线明显起伏，短时可以接近晴天 | kW |
| `overcast_p_kw` | 阴天情景的有功出力。全天偏低，起伏慢 | kW |

功率是按 500 kW 教学额定折算的数值，把水平面晴空辐照直接当成阵列收到的辐照，不是某一面真实组件的倾斜面辐照，也不是某台逆变器的抄表。

## 6. 教学用途（练习建议）

课堂起步用，用来练习读表、画曲线和比较天气形状。可自行做的练习：

1. 读入 CSV，画出三条出力，并对照晴空辐照，标出各自的峰值时刻。
2. 计算日电量和容量系数，并和上表对照。注意夜间的 0 要不要算进平均。
3. 在晴空辐照大于 0 的时刻，用出力反推近似透射率，观察多云列里的云扰动。

脚本只提供清洗和出图，不代写课程作业、课程设计或论文。

## 8. 快速使用

在仓库根目录：

```bash
python scripts/pv-daily_generate.py
python scripts/pv-daily_plot.py
```

`generate` 覆盖写回 `data.csv`。`plot` 做最小清洗（解析时间、查缺失、负的辐照和功率裁到 0、晴空辐照为 0 的时刻出力置 0、按时间去重排序、检查 15 min 间隔），在终端打印峰值、日电量和容量系数，并写出 `datasets/pv-daily/pv_daily.png`。

依赖：numpy、pandas、matplotlib。

```python
import pandas as pd
df = pd.read_csv("datasets/pv-daily/data.csv", parse_dates=["timestamp"])
df.plot(x="timestamp", y=["sunny_p_kw", "cloudy_p_kw", "overcast_p_kw"])
```
