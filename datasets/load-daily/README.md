# 典型日负荷曲线（居民 / 商业 / 工业）

## 1. 名称 / slug

- 名称：典型日负荷曲线（居民 / 商业 / 工业）
- slug：`load-daily`
- 路径：`datasets/load-daily/data.csv`

## 2. 来源与生成方式

合成数据，不是实测。

- 生成脚本：`scripts/load-daily_generate.py`
- 随机种子：`42`（`numpy.random.default_rng`）
- 做法：用钟形函数与 smoothstep 分段拼出三类典型日形状，乘以固定峰值（居民 480 kW、商业 650 kW、工业 920 kW），再叠加标准差为 1.2% 的高斯噪声，最后把日最大值归一回上述峰值。
- 钟面日期 `2026-01-07` 只是「一个工作日」的标签，不对应任何真实运行日。
- 两次运行脚本得到的 CSV 应逐字节相同。

## 4. 规模与采样间隔

- 96 行 × 4 列（约 4 KB）
- 采样间隔：15 min
- 覆盖一个典型日的钟面时刻：`2026-01-07T00:00:00` 至 `2026-01-07T23:45:00`
- 时间无时区，表示相对钟面时刻，不是带时区的绝对时间

本种子下读入后的参考量（便于核对文件，不是作业答案）：

| 列 | 最小 kW | 最大 kW | 平均 kW | 负荷率 | 峰值时刻 |
|----|---------|---------|---------|--------|----------|
| `residential_p_kw` | 104.854 | 480.000 | 192.200 | 0.400 | 19:30 |
| `commercial_p_kw` | 55.181 | 650.000 | 309.510 | 0.476 | 12:15 |
| `industrial_p_kw` | 426.346 | 920.000 | 647.579 | 0.704 | 10:15 |

负荷率 = 日平均功率 / 日最大功率。

## 5. 列说明

| 列名 | 含义 | 单位 |
|------|------|------|
| `timestamp` | 典型日钟面时刻，ISO 8601，无时区 | — |
| `residential_p_kw` | 居民台区有功功率。夜间低谷，早晨小峰，傍晚主峰 | kW |
| `commercial_p_kw` | 商业用户有功功率。夜间很低，营业时段高，午间略高 | kW |
| `industrial_p_kw` | 工业用户有功功率。夜间仍有基荷，白班高且相对平坦 | kW |

三类功率是各自对象上的教学用数值，峰值被设成同一张图里可以对照的量级，不是某一条真实馈线的抄表。

## 6. 教学用途（练习建议）

课堂起步用，用来练习读表、画曲线和比较形状。可自行做的练习：

1. 读入 CSV，画出三条曲线，标出各自的峰值时刻。
2. 计算峰谷差和负荷率，并和上表对照。
3. 重采样为小时平均，观察 15 min 噪声被平均掉之后形状还在不在。

脚本只提供清洗和出图，不代写课程作业、课程设计或论文。

## 7. 已知局限 / 免责

- 形状是人为设定的平滑曲线加小噪声，没有气象、季节、节假日、检修和随机停电。
- 只有一个典型工作日，不能外推到周、月或年电量。
- 工业曲线白班段故意比较平，峰值时刻对噪声敏感，换种子会在上午附近移动。

## 8. 快速使用

在仓库根目录：

```bash
python scripts/load-daily_generate.py
python scripts/load-daily_plot.py
```

`generate` 覆盖写回 `data.csv`。`plot` 做最小清洗（解析时间、去掉空值和负功率、按时间去重排序、检查 15 min 间隔），在终端打印峰谷与负荷率，并写出 `datasets/load-daily/load_daily.png`。

依赖：numpy、pandas、matplotlib。

```python
import pandas as pd
df = pd.read_csv("datasets/load-daily/data.csv", parse_dates=["timestamp"])
df.plot(x="timestamp", y=["residential_p_kw", "commercial_p_kw", "industrial_p_kw"])
```
